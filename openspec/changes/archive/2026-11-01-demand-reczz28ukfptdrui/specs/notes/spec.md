# Spec Delta

## Purpose

提供笔记的创建、编辑、删除与本地持久化能力，使用户能在一个页面上记录和管理个人笔记。

## ADDED Requirements

### Requirement: 用户新增笔记

当用户提交非空笔记内容时，系统 MUST 创建一条新笔记并显示在笔记列表中。

#### Scenario: 成功新增笔记
- **WHEN** 用户在笔记输入区输入非空内容并保存
- **THEN** 系统在笔记列表中显示该新笔记，并清空输入区

#### Scenario: 空内容不新增
- **WHEN** 用户在笔记内容为空或仅空白时保存
- **THEN** 系统不创建笔记，列表中不出现新条目

### Requirement: 用户编辑笔记

当用户修改已有笔记并保存时，系统 MUST 更新该笔记的显示内容。

#### Scenario: 编辑并保存笔记
- **WHEN** 用户编辑某条已有笔记的内容并保存
- **THEN** 系统在笔记列表中显示更新后的内容

### Requirement: 用户删除笔记

当用户删除某条笔记时，系统 MUST 将该笔记从列表中移除。

#### Scenario: 删除笔记
- **WHEN** 用户点击笔记的删除按钮
- **THEN** 系统将该笔记从笔记列表中移除

### Requirement: 笔记本地持久化

当页面重新加载或重新打开时，系统 MUST 从浏览器本地存储恢复笔记列表及内容。

#### Scenario: 重载后恢复笔记
- **WHEN** 用户已创建或编辑若干笔记并重新加载页面
- **THEN** 系统在笔记列表中恢复显示这些笔记及其最新内容

#### Scenario: 删除后重载保持一致
- **WHEN** 用户删除某条笔记并重新加载页面
- **THEN** 系统不显示已删除的笔记

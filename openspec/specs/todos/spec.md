# todos Specification

## Purpose
提供待办清单的创建、完成状态切换、删除与本地持久化能力，使用户能在一个页面上管理个人待办事项。

## Requirements

### Requirement: 用户新增待办

当用户提交非空待办内容时，系统 MUST 将新待办添加到待办清单并显示在列表中。

#### Scenario: 成功新增待办
- **WHEN** 用户在待办输入框输入非空内容并提交
- **THEN** 系统在待办列表中显示该新待办，并清空输入框

#### Scenario: 空内容不新增
- **WHEN** 用户在待办输入框内容为空或仅空白时提交
- **THEN** 系统不新增待办，列表中不出现新条目

### Requirement: 用户切换待办完成状态

当用户对待办执行完成状态切换时，系统 MUST 在该待办的已完成与未完成状态之间切换。

#### Scenario: 切换完成状态
- **WHEN** 用户点击待办的完成状态控件
- **THEN** 系统将该待办从未完成切换为已完成，再次点击则切换回未完成

### Requirement: 用户删除待办

当用户删除某条待办时，系统 MUST 将该待办从清单中移除。

#### Scenario: 删除待办
- **WHEN** 用户点击待办的删除按钮
- **THEN** 系统将该待办从待办列表中移除

### Requirement: 待办本地持久化

当页面重新加载或重新打开时，系统 MUST 从浏览器本地存储恢复待办清单及其完成状态。

#### Scenario: 重载后恢复待办
- **WHEN** 用户已新增若干待办并重新加载页面
- **THEN** 系统在待办列表中恢复显示这些待办及其完成状态

#### Scenario: 删除后重载保持一致
- **WHEN** 用户删除某条待办并重新加载页面
- **THEN** 系统不显示已删除的待办
